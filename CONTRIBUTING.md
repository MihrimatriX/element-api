# Contributing

## Commit messages

Use [Conventional Commits](https://www.conventionalcommits.org/):

```
feat(web): polish lab void chrome
fix(order): timing-safe INTERNAL_API_KEY compare
docs(ci): Jenkins path matrix
chore: add MIT LICENSE
```

Types: `feat`, `fix`, `docs`, `test`, `refactor`, `chore`, `ci`, `perf`. Scope optional (service or area).

## How to present / test (single list)

| Intent | Command |
|--------|---------|
| **present** full platform | `./deploy/scripts/present-platform.ps1` → http://localhost:6241 |
| **present** atlas-only | `./deploy/scripts/present-local.ps1` → http://127.0.0.1:5080 |
| **present** public env | `./deploy/scripts/present-public.ps1 -Environment Dev` |
| **up** (compose alias) | `docker compose --env-file docker/.env up -d --build` |
| **test** (full gate) | `./deploy/scripts/test-all.ps1` (+ `-Browser` / `-Integration` / `-Live` / `-Recovery`), shortcut `./scripts/test.ps1` |
| **lint** | `./scripts/lint.ps1` (web ESLint + order-service tsc) |
| .NET unit | `./deploy/scripts/test-unit.ps1` (Gateway 20 + Services 115) |
| order unit | `npm --prefix order-service test` and `npm --prefix order-service run check` |
| Java unit | `mvn -f wallet-service test` / `mvn -f inventory-service test` |
| web unit | `npm --prefix web-app test` |
| integration | `dotnet test deploy/tests/Element.Services.IntegrationTests --filter "Category=Integration"` (Docker; run `npm --prefix order-service run build` first) |
| web e2e, accounts off | `npm --prefix web-app run test:e2e` (`web-app/e2e/`) |
| web e2e, account flows | `npm --prefix web-app run test:e2e:auth` (`web-app/e2e-auth/`, mocked identity API) |
| web e2e, live commerce | `npm --prefix web-app run test:e2e:live` (`web-app/e2e-live/`, full platform on :6241) |
| live API scripts | `node deploy/scripts/test-scientific-api.mjs`, `node deploy/scripts/test-e2e.mjs`, `./deploy/scripts/test-saga.ps1`, `./deploy/scripts/test-smoke.ps1`, `node deploy/scripts/test-platform.mjs` |
| secret scan | `node deploy/scripts/secret-scan.mjs` |

Playwright needs `npx playwright install chromium` once, run inside `web-app/`.

Root convenience wrappers: `scripts/test.ps1`, `scripts/lint.ps1`, `scripts/up.ps1`, `scripts/present.ps1`.

CI is **Jenkins** path-based Multibranch — see [docs/CI-JENKINS.md](./docs/CI-JENKINS.md). Do not add GitHub Actions as the primary gate.

## Docs that follow the code

- Changing a service: update its page in [docs/kilavuz/](./docs/kilavuz/README.md) (Turkish; one page per service, read in the app at `/kilavuz`). `web-app/scripts/write-guide.mjs` turns the pages into `web-app/src/data/guide.json` (git-ignored, regenerated by `npm run dev`, `build` and `test`) and fails with a line number when a page breaks the template.
- Changing the web UI: follow [docs/memory-bank/design-system.md](./docs/memory-bank/design-system.md); the component gallery is `/_ui` on the dev server.

Do not commit secrets (`.env*`, real `register_payload.json`). Prefer `register_payload.example.json`.
