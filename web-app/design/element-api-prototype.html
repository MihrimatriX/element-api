Element API ürünü

Element verisini keşfet, değerle, Elemental'da satın al.

SWAPI hissindeki API tarayıcı, bankacılık gibi değer ekranı ve e-ticaret sepeti aynı element verisiyle çalışır. Seçilen element sayfalar arasında taşınır.

Periyodik tabloyu aç Elemental mağazayı aç

Hızlı başlangıç

GET 
curl "https://api.element.dev/v1/elements/C"

{
  "symbol": "C",
  "name": "Karbon",
  "links": {
    "valuation": "/elements/C/valuation",
    "orders": "/elemental/orders?symbol=C"
  }
}

Sayfayı aç

API haritası

Her sayfanın ayrı endpoint odağı var.

GET
/elements

Periyodik tablo sayfasını, arama ve kategori filtrelerini besler.

GET
/elements/{symbol}/valuation

Değer sayfasındaki model fiyat, teminat ve likidite alanlarını döndürür.

POST
/elemental/orders

Elemental mağazada hazırlanan sepeti doğrular ve sipariş kaydını üretir.

ElementAPI prototipi: index.html giriş; periyodik tablo, değer ekranı ve Elemental mağaza ayrı HTML dosyalarıdır.
